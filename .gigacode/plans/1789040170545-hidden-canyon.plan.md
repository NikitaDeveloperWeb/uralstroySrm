# Финансовое планирование - План реализации

## Концепция

Новый раздел для планирования ожидаемых доходов с проектов на конкретные недели/месяцы с сравнением плана и факта.

### Основная идея
- Создаёшь **плановый период** (неделя/месяц)
- Для каждого проекта указываешь **ожидаемую сумму** дохода
- Система автоматически считает **факт** по `ProjectTransaction` за этот период
- Визуально показываешь **план vs факт** с процентами выполнения

## Архитектура

### Новая модель в Prisma

```prisma
model FinancialPlan {
  id          Int      @id @default(autoincrement())
  projectId   Int
  periodFrom  DateTime // Начало периода (неделя/месяц)
  periodTo    DateTime // Конец периода
  plannedAmount Int   // Запланированная сумма
  comment     String?
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
  
  project     Project  @relation(fields: [projectId], references: [id])
  
  @@index([periodFrom, periodTo])
  @@index([projectId])
}
```

### API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/financial-plans` | Получить все планы (с фильтрацией по периоду) |
| POST | `/api/financial-plans` | Создать план |
| PUT | `/api/financial-plans/[id]` | Обновить план |
| DELETE | `/api/financial-plans/[id]` | Удалить план |
| GET | `/api/financial-plans/summary` | Получить сводку план/факт за период |

## Шаг 3: API Routes

### GET `/api/financial-plans`
- Query params: `periodFrom`, `periodTo` (опционально)
- Возвращает все планы с relation `project` (name, code)
- Если переданы даты - фильтрует по пересечению периодов

### POST `/api/financial-plans`
- Тело: валидированная схема
- Создает план, возвращает с relation

### PUT `/api/financial-plans/[id]`
- Обновляет plan, проверяет ownership

### DELETE `/api/financial-plans/[id]`
- Удаляет план

### GET `/api/financial-plans/summary`
- Query params: `periodFrom`, `periodTo`
- Возвращает:
  ```json
  {
    "periodFrom": "...",
    "periodTo": "...",
    "totalPlanned": 1000000,
    "totalActual": 850000,
    "projects": [
      {
        "projectId": 1,
        "projectName": "Объект №1",
        "projectCode": "PRJ-001",
        "plannedAmount": 500000,
        "actualAmount": 450000,
        "progress": 90
      }
    ]
  }
  ```
- `actualAmount` считается через Prisma query к `ProjectTransaction` WHERE projectId IN (...) AND date >= periodFrom AND date <= periodTo

## Верификация

1. `npx prisma migrate dev` - миграция проходит без ошибок
2. `npm run build` - сборка без ошибок
3. Открыть `/financial-planning`:
   - Видна таблица с проектами
   - Кнопка "Создать план" открывает модалку
   - Выбор периода переключает данные
   - Summary cards показывают правильные суммы
4. Создать план:
   - Выбрать проект и сумму
   - План появляется в таблице
5. Проверить факт:
   - Создать `ProjectTransaction` на период
   - Факт обновляется автоматически
6. Проверить удаление и редактирование плана
