# RBAC — Роли и права доступа

## Роли
- **ADMIN** — полный доступ ко всему
- **MANAGER** — только: Dashboard, Проекты, Канбан, Клиенты, Документы

## Шаги реализации

### 1. Prisma schema — добавить UserRole enum
**Файл:** `prisma/schema.prisma`
- Добавить `enum UserRole { ADMIN, MANAGER, WORKER }`
- Изменить `role String @default("admin")` → `role UserRole @default(ADMIN)`
- Запустить `npx prisma migrate dev --name add_user_role_enum`

### 2. Auth helper
**Новый файл:** `shared/lib/auth.ts`
- `getAuthUser()` — декодирует session cookie, возвращает пользователя из БД
- `requireAuth()` — бросает ошибку если не авторизован
- `hasRole()` — проверка роли

### 3. Middleware
**Новый файл:** `middleware.ts`
- Проверяет авторизацию по session cookie
- Перенаправляет на `/login` если не авторизован
- Блокирует менеджера от админских роутов (`/api/users`, `/api/employees`, `/api/finance` и т.д.)
- Добавляет `X-User-Role` header в response

### 4. NavMenu — фильтрация по ролям
**Новый файл:** `shared/components/navigation/NavMenuWrapper.tsx`
- Server component, вызывает `getAuthUser()`
- Для MANAGER передаёт только разрешённые пункты меню
- Для ADMIN — все пункты

**Модификация:** `shared/components/navigation/NavMenu.tsx`
- Добавить prop `allowedItems` вместо хардкода

**Модификация:** `app/layout.tsx`
- Заменить `<NavMenu />` на `<NavMenuWrapper />`

### 5. Защита API роутов
**Модификация:** `app/api/users/route.ts` — добавить проверку ADMIN
**Модификация:** `app/api/users/[id]/route.ts` — добавить проверку ADMIN на PATCH/DELETE

### 6. Login — обработка redirect param
**Модификация:** `app/login/page.tsx`
- После логина перенаправлять на `?redirect=...` если есть параметр

## Верификация
1. `npx prisma migrate dev --name add_user_role_enum`
2. `npm run build` — без ошибок
3. Зайти как admin — все разделы видны
4. Создать manager через PATCH /api/users/[id]
5. Зайти как manager — видны только Проекты, Клиенты, Документы
6. Попытаться получить `/api/employees` как manager — 403
7. Выйти из системы — доступ к `/dashboard` перенаправляет на `/login`
