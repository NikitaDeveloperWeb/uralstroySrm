# Поставщики и отсрочка оплаты материалов

## Проблема
Нет учёта отсрочки оплаты за материалы. Компания забирает материалы у поставщиков и платит позже. Нужно отслеживать:
- Забранные материалы (долг перед поставщиком)
- Оплаченные суммы (выплаты поставщику)
- Текущий баланс (долг или переплата)

## Решение
Расширим существующие модели `WarehouseMovement` и `Expense`, добавив связь с поставщиком.

---

## План реализации

### 1. Schema changes (Prisma)

**Файл:** `prisma/schema.prisma`

#### WarehouseMovement — добавить поля:
```prisma
model WarehouseMovement {
  // ... existing fields ...
  supplierId  Int?
  amount      Int?   // стоимость забранных материалов
  supplier    Supplier? @relation(fields: [supplierId], references: [id], onDelete: Cascade)
}
```

#### Expense — добавить поле:
```prisma
model Expense {
  // ... existing fields ...
  supplierId  Int?
  supplier    Supplier? @relation(fields: [supplierId], references: [id])
}
```

## Логика расчёта баланса

```
Долг перед поставщиком = SUM(WarehouseMovement.amount WHERE type='income' AND supplierId=X)
Оплачено = SUM(Expense.amount WHERE supplierId=X)
Баланс = Долг - Оплачено

Если Баланс > 0 → мы должны поставщику
Если Баланс < 0 → поставщик должен нам (переплата)
```
