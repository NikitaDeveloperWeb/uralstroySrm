# Kanban Board for Project Milestones

## Цель
Реализовать канбан-доску для этапов проекта с drag-and-drop между 4 колонками: Новые → В работе → На проверке → Завершено.

## Архитектура

### 1. База данных — новая модель Milestone
**Файл:** `prisma/schema.prisma`

```prisma
model Milestone {
  id          Int      @id @default(autoincrement())
  projectId   Int
  title       String
  description String?
  status      String   @default("new") // new, in-progress, review, done
  order       Int      @default(0)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
  project     Project  @relation(fields: [projectId], references: [id], onDelete: Cascade)

  @@index([projectId])
  @@map("milestones")
}
```

**Команды:** `npx prisma migrate dev --name add_milestones` && `npx prisma generate`

## Верификация
1. `npx prisma migrate dev --name add_milestones` — миграция без ошибок
2. `npx tsc --noEmit` — компиляция без ошибок типов
3. Открыть проект → секция "Этапы (Kanban)" видна
4. Создать этап → появляется в колонке "Новые"
5. Drag-and-drop в другую колонку → статус обновляется
6. Inline-редактирование → сохраняется
7. Удаление → подтверждение + удаление
8. Refresh → данные сохраняются
