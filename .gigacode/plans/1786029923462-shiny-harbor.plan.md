# План доработки системы сметы работ и материалов

## Контекст

Сейчас в приложении есть базовая реализация сметы материалов (`MaterialEstimate`) и сметы выполненных работ (`CompletedWork`), которая управляется через модальные окна на странице деталей проекта (`app/projects/[id]/page.tsx`).

**Текущие проблемы:**
1. **Удалить всё и создать заново** — при сохранении сметы все старые записи удаляются и создаются новые. Это хрупкий подход.
2. **Отсутствуют PATCH эндпоинты** для обновления отдельных записей.
3. **Нет выделенной страницы** для управления сметами с фильтрацией по проектам.
4. **Нет навигационной ссылки** на сметы в боковом меню.
5. **Нет типов** для `MaterialEstimate` и `CompletedWork` в shared/types.

---
