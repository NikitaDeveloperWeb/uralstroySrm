# Подключение реальных данных из БД к UI

## Выбор библиотеки управления состоянием

**Zustand** — лучший выбор для этого проекта:
- **Redux Toolkit**: избыточный boilerplate (dispatch, reducers, selectors, store setup) для 11 страниц с простым CRUD
- **Хуки (useState + fetch)**: придётся дублировать логику загрузки/кеширования на каждой странице, нет deduplication запросов, нет loading/error state
- **Zustand**: ~1KB, zero boilerplate, отличная TS-поддержка, хуки для каждого ресурса, одна установка пакета

## План реализации

### 2. Создание stores (`shared/stores/`)

Один файл `projectStore.ts` — централизованное управление проектами и бригами:

```typescript
// shared/stores/projectStore.ts
import { create } from 'zustand';

type Project = {
  id: number; name: string; code: string; type: string;
  area: string; address: string; cost: string; date: string;
  complexity: string; status: string; prepayment: string;
  prepaymentDate: string; brigadeId: number | null;
  materials: any[]; completedWorks: any[];
};

type Brigade = { id: number; name: string; leaderId: number; memberIds: string; skills: string };

interface ProjectState {
  projects: Project[];
  brigades: Brigade[];
  loading: boolean;
  error: string | null;
  
  fetchProjects: () => Promise<void>;
  fetchBrigades: () => Promise<void>;
  updateProject: (id: number, data: Partial<Project>) => Promise<void>;
  addProject: (data: Partial<Project>) => Promise<void>;
  deleteProject: (id: number) => Promise<void>;
}

export const useProjectStore = create<ProjectState>((set) => ({
  projects: [], brigades: [], loading: false, error: null,
  
  fetchProjects: async () => {
    set({ loading: true, error: null });
    const res = await fetch('/api/projects');
    const json = await res.json();
    set({ projects: json.data, loading: false });
  },
  
  fetchBrigades: async () => {
    const res = await fetch('/api/brigades');
    const json = await res.json();
    set({ brigades: json.data });
  },
  
  updateProject: async (id, data) => {
    await fetch(`/api/projects/${id}`, {
      method: 'PATCH', body: JSON.stringify(data), headers: { 'Content-Type': 'application/json' }
    });
    // Optimistic update
    set((s) => ({ projects: s.projects.map(p => p.id === id ? { ...p, ...data } : p) }));
  },
  
  addProject: async (data) => {
    const res = await fetch('/api/projects', {
      method: 'POST', body: JSON.stringify(data), headers: { 'Content-Type': 'application/json' }
    });
    const json = await res.json();
    set((s) => ({ projects: [json.data, ...s.projects] }));
  },
  
  deleteProject: async (id) => {
    await fetch(`/api/projects/${id}`, { method: 'DELETE' });
    set((s) => ({ projects: s.projects.filter(p => p.id !== id) }));
  },
}));
```

### 3. Создание generic hook для загруженных данных

Файл `shared/hooks/useProjects.ts` — wrapper для автоматической загрузки:

```typescript
// shared/hooks/useProjects.ts
import { useEffect } from 'react';
import { useProjectStore } from '@/shared/stores/projectStore';

export function useProjects() {
  const { projects, brigades, fetchProjects, fetchBrigades, loading, error } = useProjectStore();
  
  useEffect(() => {
    fetchProjects();
    fetchBrigades();
  }, []);
  
  return { projects, brigades, loading, error, ...useProjectStore.getState() };
}
```

### 4. Подключение страниц

#### `/projects/page.tsx`
- Удалить `useState<Project[]>(initialProjects)`
- Заменить на `const { projects, brigades } = useProjects()`
- Подключить `fetchProjects` на создание (handleSubmit AddObjectForm)
- Подключить `deleteProject` в handleDelete
- Подключить `updateProject` в handleSaveEdit
- BrigadeId dropdown → загружен из API (`brigades` из store)

#### `/projects/[id]/page.tsx`
- Удалить `useState<ObjectItem[]>(initialObjects)` (500 строк моковых данных)
- Заменить на `const { projects, brigades, loading } = useProjects()`
- Фильтр объекта: `obj = projects.find(o => o.id === id)`
- Загрузка данных материалов и выполненных работ через `/api/material-estimates?projectId=${id}` и `/api/completed-works?projectId=${id}`
- SAVE в edit-модалке → `PATCH /api/projects/${id}`
- Статус toggle → `PATCH /api/projects/${id}` с `{ status: newStatus }`
