# План: История транзакций проектов

## Контекст
Нужно добавить систему транзакций для привязки платежей к проектам. Все транзакции — это доходы (платежи клиента). Первая транзакция автоматически становится предоплатой. История транзакций отображается в отдельной вкладке на странице объекта.

## Требования
- **Модель Transaction**: projectId, amount (сумма), date (дата), comment (комментарий)
- **Первая транзакция**: автоматически устанавливает prepayment и prepaymentDate на проекте
- **CRUD**: создание, редактирование, удаление транзакций
- **UI**: отдельная вкладка "Транзакции" на странице проекта (`/projects/[id]`)
- **Только просмотр** истории транзакций для текущего баланса (редактирование/удаление — через UI вкладки)

## Реализация

### 1. База данных (Prisma)

**Файл:** `prisma/schema.prisma`

Добавить модель `ProjectTransaction`:
```prisma
model ProjectTransaction {
  id        Int      @id @default(autoincrement())
  projectId Int
  project   Project  @relation(fields: [projectId], references: [id])
  amount    Int      // сумма в рублях
  date      DateTime // дата транзакции
  comment   String?  // комментарий
  
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  @@map("project_transactions")
}
```

Добавить relation в модель `Project`:
```prisma
transactions ProjectTransaction[]
```

**Действие:** `npx prisma migrate dev --name add_project_transactions`

### 2. Валидация (Zod schema)

export const createProjectTransactionSchema = z.object({

  amount: z.number().int().positive(),
  date: z.string().or(z.date()),
  comment: z.string().optional(),

  amount: z.number().int().positive().optional(),

### 3. API маршруты

**Файл (новый):** `app/api/projects/[id]/transactions/route.ts`
- `GET` — получить все транзакции проекта
- `POST` — создать новую транзакцию (если первая — обновить prepayment на проекте)

**Файл (новый):** `app/api/projects/[id]/transactions/[transactionId]/route.ts`
- `PATCH` — обновить транзакцию
- `DELETE` — удалить транзакцию

**Логика при создании транзакции:**
1. Создать транзакцию в БД
2. Если это первая транзакция для проекта:
   - Обновить `prepayment` = amount первой транзакции
   - Обновить `prepaymentDate` = date первой транзакции
3. Вернуть созданный объект

**Логика при удалении первой транзакции:**
1. Если удаляется первая транзакция:
   - Найти следующую транзакцию (сортировка по date ASC)
   - Обновить `prepayment` и `prepaymentDate` на проекте
   - Если транзакций больше нет — сбросить prepayment в null

**Логика при обновлении первой транзакции:**
1. Обновить транзакцию
2. Обновить `prepayment` и `prepaymentDate` на проекте

## Верификация

1. Создать проект → вкладка "Транзакции" пуста
2. Создать первую транзакцию → prepayment на проекте обновляется
3. Создать вторую транзакцию → prepayment не меняется
4. Удалить первую транзакцию → prepayment обновляется на вторую
5. Редактировать транзакцию → изменения применяются
6. Прогресс-бар показывает % оплаты
7. TypeScript компиляция проходит без ошибок
