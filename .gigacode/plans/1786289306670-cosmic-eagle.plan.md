# План: Улучшение UX модальных окон сметы

## Контекст

Модальные окна смет материалов и выполненных работ на странице `/projects/[id]` уже имеют базовую функциональность:
- Просмотр записей
- Режим редактирования (inline input) для всего списка сразу
- Точечные CRUD операции (PATCH/POST/DELETE) при сохранении
- Загрузка шаблонов

**Что нужно улучшить:**
1. Добавить кнопку **"+"** для добавления новой строки в режиме редактирования
2. Добавить кнопку **🗑** (удалить строку) для каждой строки в режиме редактирования
3. Добавить кнопку **"+"** для добавления новой строки в режиме просмотра
4. Улучшить UX: при добавлении строки автоматически переходить в режим редактирования
5. Добавить кнопку **"Шаблоны"** для быстрого выбора шаблона без открытия модального окна

---

## Реализация

### Изменяемый файл: `app/projects/[id]/page.tsx`

#### 1. Добавить/изменить функции управления строками

**Для материалов:**
```
addMaterialRow() -> уже есть, но нужно:
  - При добавлении через кнопку "+" в режиме просмотра -> переходить в режим редактирования
  - Новая строка с пустыми полями для ввода
```

**Для работ:**


#### 2. Добавить кнопки удаления строк

**Для материалов:**
```
removeMaterialRow(index) -> уже есть
Нужно добавить кнопку 🗑 в каждую строку режима редактирования
```

**Для работ:**
```
removeWorkRow(index) -> уже есть
Нужно добавить кнопку 🗑 в каждую строку режима редактирования
```

#### 3. Добавить кнопку "+" для добавления строки

**Режим просмотра:**
- Кнопка "+" в каждой строке (справа, рядом с pencil)
- При клике -> добавляет новую пустую строку в editMaterials/editWorks
- Переходит в режим редактирования

**Режим редактирования:**
- Кнопка "+" над таблицей (рядом с "Редактировать")
- При клике -> добавляет новую пустую строку в конец
- Остаётся в режиме редактирования

#### 4. Кнопка "Шаблоны"

- В режиме просмотра добавить кнопку "📑 Шаблоны"
- При клике -> показывает dropdown/модалку с шаблонами
- При выборе шаблона -> добавляет запись и переходит в режим редактирования

## Детальный план изменений

### Шаг 1: Кнопки "+" для добавления строк

**В режиме просмотра (non-edit mode):**
```tsx
// Для каждой строки материалов добавить колонку "Действия":
<button onClick={() => { addMaterialRow(); setMaterialsEditIndex(0); }}>
  <Plus className="w-4 h-4" />
</button>
```

**В режиме редактирования:**
```tsx
// Перед таблицей, рядом с кнопкой "Редактировать":
<Button onClick={addMaterialRow} variant="outline" size="sm">
  <Plus className="w-4 h-4 mr-1" /> Добавить строку
</Button>
```

## Верификация

1. **Добавление строки в режиме просмотра:** кнопка "+" -> новая строка появляется, режим редактирования активируется
2. **Добавление строки в режиме редактирования:** кнопка "+ Добавить строку" -> новая пустая строка в конце таблицы
3. **Удаление строки:** кнопка 🗑 -> строка удаляется, остальные сдвигаются
4. **Шаблоны:** кнопка "📑 Шаблоны" -> модалка с шаблонами -> выбор -> строка добавлена
5. **Сохранение:** после изменений нажать Save -> данные отправляются на сервер
6. **Отмена:** после добавления строки нажать Cancel -> строка не добавляется
