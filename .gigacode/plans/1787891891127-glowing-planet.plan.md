## ТЕКУЩАЯ ПРОБЛЕМА
PATCH запрос на `/api/material-estimates/[id]` возвращает **400 Bad Request**.

**Данные которые отправляются:**
```json
{
  "name": "Вагонка сосновая",
  "quantity": "10",
  "cost": 200,
  "category": "Отделка"
}
```

**Возможные причины:**
1. `cost: 200` — Zod-схема ожидает `z.coerce.number().optional()`, но `cost` уже число. Возможно проблема в `.int()` — нужно проверить.
2. `handlePrismaError` может возвращать 400 вместо 500 для некоторых ошибок Prisma.
3. `cost: 0` может не проходить валидацию.

**Что нужно проверить:**
- Серверные логи (console.error) — там есть `console.log('PATCH material-estimates/[id] body:', body)` и `console.error('PATCH ... error:', error)`
- Возможно `handlePrismaError` нужно заменить на прямой `errorResponse(error.message, 400)`
- Возможно `cost: z.coerce.number().optional()` ломается на `0` — стоит добавить `.min(0)`
