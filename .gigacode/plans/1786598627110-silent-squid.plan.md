# План: Реализация "Карты объекта"

## Контекст

Поля для "карты объекта" определены в Prisma schema и TypeScript типах, но UI для их ввода и отображения **не реализован**. Необходимо добавить поля в формы редактирования и отображение на странице деталей проекта.

### Существующее состояние
- **Database Schema**: 14 полей в модели Project (floors, hasMansard, roofType, roofColor, hasVeranda, verandaSize, hasPorhch, foundations, walls, insulation, windows, doorType, communication, description)
- **TypeScript Types**: `Project` и `UpdateProjectInput` интерфейсы содержат все поля
- **API Routes**: Generic project PATCH endpoint покрывает обновление
- **UI**: НЕ реализовано — поля не отображаются ни в формах, ни на странице деталей

## Реализация

### Шаг 1: Обновить страницу деталей проекта (`app/projects/[id]/page.tsx`)

Добавить секцию "Карта объекта" на страницу деталей проекта (после блока с предоплатой, до кнопок смет):

1. **Новая секция** с заголовком "🏗 Карта объекта"
2. **Отображение полей**:
   - Количество этажей (floors)
   - Тип крыши (roofType) — с иконками для типов: односкатная, двускатная, вальмовая, шатровая
   - Цвет крыши (roofColor)
   - Есть ли мансарда (hasMansard) — бейдж "Да"/"Нет"
   - Есть ли веранда (hasVeranda) — бейдж "Да"/"Нет", если да — показать размер
   - Есть ли крыльцо (hasPorhch) — бейдж "Да"/"Нет"
   - Тип фундамента (foundations)
   - Тип стен (walls)
   - Тип утепления (insulation)
   - Тип окон (windows)
   - Тип двери (doorType)
   - Коммуникации (communication)
   - Описание (description) — в отдельном блоке, если есть

3. **Визуальное оформление**: Карточки с иконками, сетка 2-3 колонки, бейджи для boolean полей

### Шаг 2: Обновить форму редактирования на странице деталей (`app/projects/[id]/page.tsx`)

Добавить поля карты объекта в существующий Modal редактирования объекта (в `showEditModal`):

Новые поля в форме редактирования (после блока предоплаты):
- **Количество этажей**: input type="number", min="1"
- **Тип крыши**: select с опциями (односкатная, двускатная, вальмовая, шатровая, другое)
- **Цвет крыши**: input type="text"
- **Есть ли мансарда**: checkbox
- **Есть ли веранда**: checkbox
- **Размер веранды**: input type="text" (показывать только если веранда включена)
- **Есть ли крыльцо**: checkbox
- **Тип фундамента**: select (ленточный, свайный, плитный, столбчатый, другое)
- **Тип стен**: select (кирпич, газобетон, дерево, каркас, SIP-панели, другое)
- **Тип утепления**: input type="text"
- **Тип окон**: select (пластиковые, деревянные, деревянно-алюминиевые, другое)
- **Тип двери**: input type="text"
- **Коммуникации**: textarea (газ, вода, электричество, канализация)
- **Описание**: textarea (многострочное)

## Верификация

1. **Создание объекта**: Добавить новый объект с полями карты объекта → проверить сохранение в БД
2. **Редактирование объекта**: Открыть детали → редактировать карту объекта → сохранить → проверить отображение
3. **Отображение на странице деталей**: Все поля карты объекта отображаются корректно
4. **Список объектов**: Редактирование карты объекта из модального окна в списке
5. **API**: Прямой запрос к API с полями карты объекта возвращает корректные данные
