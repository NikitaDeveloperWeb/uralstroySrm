# План: Раздел "Документы"

## Цель
Создать раздел "Документы" для просмотра и скачивания шаблонов договоров, отчетов и графиков.

## Архитектура
- **Файлы документов** хранятся локально в `public/docs/` (просто и эффективно)
- **Metadata** документов хранится в Prisma (название, категория, описание, файл)
- **Страница** в `app/documents/page.tsx` со списком по категориям
- **API routes** для CRUD операций с метаданными документов
- **Навигация** добавлена в NavMenu

## Реализация

### 1. Prisma Schema — новая модель Document
**Файл:** `prisma/schema.prisma`

```prisma
model Document {
  id          String   @id @default(cuid())
  name        String
  description String?
  category    String   // "contracts", "reports", "schedules"
  fileName    String   // имя файла в public/docs/
  mimeType    String?
  fileSize    Int?     // размер в байтах
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
}
```

### 2. Миграция БД
```bash
npx prisma migrate dev --name add_documents
npx prisma generate
```

### 3. API Routes

**Файл:** `app/api/documents/route.ts`
- GET — список документов (с фильтрацией по категории)
- POST — создание метаданных документа
- DELETE — удаление метаданных

### 4. Страница документов

**Файл:** `app/documents/page.tsx`

Структура:
- Заголовок "Документы"
- Табы по категориям: Договоры, Отчеты, Графики
- Список документов в каждой категории:
  - Иконка типа файла
  - Название
  - Описание
  - Кнопка "Скачать" (ссылка на `/docs/{fileName}`)
- Кнопка "Загрузить документ" (модальное окно с формой)

**Компоненты:**
- `DocumentCard.tsx` — карточка документа
- `DocumentModal.tsx` — модальное окно для загрузки

### 5. Навигация

**Файл:** `shared/components/navigation/NavMenu.tsx`

Добавить пункт в `navItems`:
```tsx
{
  name: 'Документы',
  href: '/documents',
  icon: <DocumentIcon />
}
```

### 6. Структура файлов

```
public/
└── docs/
    ├── contracts/
    │   ├── contract-template.docx
    │   └── addendum-template.docx
    ├── reports/
    │   ├── act-template.docx
    │   └── progress-report.xlsx
    └── schedules/
        ├── gantt-template.xlsx
        └── work-schedule.docx
```

### 7. Загрузка начальных данных

Создать seed-скрипт `prisma/seed-documents.ts`:
- Добавить типовые шаблоны документов
- Заполнить категории примерами

- Tailwind CSS v4

## Верификация
1. `npx prisma migrate dev` — миграция проходит без ошибок
2. `npm run dev` — приложение запускается
3. Переход в "Документы" — страница загружается
4. Табы категорий переключаются
5. Кнопка "Скачать" открывает файл
6. Кнопка "Загрузить" — модальное окно работает
