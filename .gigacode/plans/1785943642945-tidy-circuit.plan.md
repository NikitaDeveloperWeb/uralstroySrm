# Рефакторинг: projects/[id]/page.tsx (997 строк → ~400 строк)

## Цель
Сократить количество строк с 997 до ~350-400 путём выделения компонентов и утилит.

## Файлы для создания/изменения

### Новые файлы:
1. `shared/components/projects/ProjectDetail.tsx` — основной компонент страницы
2. `shared/components/projects/ProjectDetailHeader.tsx` — шапка с названием, статусом, бригадой
3. `shared/components/projects/ProjectDetailInfo.tsx` — сетка с информацией (площадь, стоимость, адрес и т.д.)
4. `shared/components/projects/ProjectDetailPrepayment.tsx` — блок предоплаты
5. `shared/components/projects/ProjectDetailCosts.tsx` — таблица стоимости квадратов
6. `shared/components/projects/ProjectDetailLabor.tsx` — таблица оплаты труда
7. `shared/components/projects/ProjectDetailManager.tsx` — блок оплаты менеджеру
8. `shared/components/projects/EditableTable.tsx` — универсальная таблица с inline-редактированием (замена дублированию модалок материалов/работ)
9. `shared/components/projects/EditForm.tsx` — модальное окно редактирования проекта
10. `shared/components/projects/ReportModal.tsx` — модалка создания отчета
11. `shared/components/projects/projectDetailUtils.ts` — утилиты (JSON-парсинг, форматирование)
12. `app/projects/[id]/page.tsx` — минимальный entry-point

---

## План рефакторинга

### Шаг 1: Утилиты (`shared/components/projects/projectDetailUtils.ts`)
- `parseJsonSafe<T>(value: unknown): T` — обёртка над JSON.parse с fallback
- `formatCurrency(value: number): string` — `toLocaleString('ru-RU')`
- `calculatePercentage(part: number, total: number): string` — процент с точностью
- Константы: `MATERIALS_BREAKDOWN` (каркасы, липа, сосна и т.д.), `PAYMENT_CATEGORIES`, `TYPE_ICONS`, `STATUS_COLORS`, `COMPLEXITY_COLORS`

### Шаг 2: EditableTable (`shared/components/projects/EditableTable.tsx`)
- Универсальный компонент для модалок материалов и работ
- Props: `items`, `setItems`, `isEditing`, `onSave`, `onCancel`, `columns` (массив колонок с рендерами)
- Убирает дублирование ~200 строк кода между модалками материалов и работ
- Поддержка inline-редактирования, добавления/удаления строк, итогов

### Шаг 3: ProjectDetailHeader (`shared/components/projects/ProjectDetailHeader.tsx`)
- Тип объекта с иконкой, название, адрес
- Статус-бейджи
- Кнопка редактирования
- Секция бригады (skills, состав)

### Шаг 4: ProjectDetailInfo (`shared/components/projects/ProjectDetailInfo.tsx`)
- Grid с: тип, площадь, стоимость, дата сдачи, сложность, адрес
- Без изменений логики, только вынос в компонент

### Шаг 5: ProjectDetailPrepayment (`shared/components/projects/ProjectDetailPrepayment.tsx`)
- Блок предоплаты с суммой, датой, остатком, прогресс-баром

### Шаг 6: ProjectDetailCosts (`shared/components/projects/ProjectDetailCosts.tsx`)
- Таблица "Стоимость квадратов" (каркасы, липа, сосна, утеплитель, стропила)
- Использует `MATERIALS_BREAKDOWN` константу вместо хардкода

### Шаг 7: ProjectDetailLabor (`shared/components/projects/ProjectDetailLabor.tsx`)
- Таблица "Оплата труда" с paymentCategories
- Статус-кнопки (выполнен/не выполнен)

### Шаг 8: ProjectDetailManager (`shared/components/projects/ProjectDetailManager.tsx`)
- Простой блок: стоимость объекта, % менеджера, сумма

### Шаг 9: EditForm (`shared/components/projects/EditForm.tsx`)
- Модальное окно редактирования проекта
- Поля: название, тип, площадь, адрес, стоимость, дата сдачи, сложность, статус, код, предоплата, дата предоплаты
- Форматирование: 2 колонки, сетка

### Шаг 10: ReportModal (`shared/components/projects/ReportModal.tsx`)
- Поля: дата отчета, период с/по, комментарий
- Кнопки: создать/отмена

### Шаг 11: ProjectDetail (`shared/components/projects/ProjectDetail.tsx`)
- Основной компонент, собирает всё вместе
- State management: showEditModal, showMaterialsModal, showWorkModal, showReportModal
- Effects: fetch project detail, materials, works
- Renders:
  - ProjectDetailHeader
  - Status change buttons
  - ProjectDetailInfo
  - ProjectDetailPrepayment (conditional)
  - Кнопки: смета материалов, смета работ, печать
  - Модалки: EditableTable (×2), EditForm, ReportModal
- Около 150-200 строк вместо 997

### Шаг 12: Entry-point (`app/projects/[id]/page.tsx`)
- Минимальный файл (~15 строк):
```tsx
'use client';
import { useParams } from 'next/navigation';
import { ProjectDetail } from '@/shared/components/projects/ProjectDetail';

export default function ObjectDetailPage() {
  const id = useParams().id;
  return <ProjectDetail projectId={Number(id)} />;
}
```
