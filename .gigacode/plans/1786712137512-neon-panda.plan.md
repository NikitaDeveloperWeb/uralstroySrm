# Рефакторинг страницы проектов (Object Card Edit)

## Цель
Создать единый компонент `ProjectEditForm` для редактирования всех полей проекта (базовые + карта объекта) и использовать его в `app/projects/page.tsx`.

## Анализ

### Текущая ситуация
1. **`app/projects/page.tsx`** — содержит дублирующуюся встроенную форму (~200 строк) для редактирования всех полей проекта
2. **`shared/components/projects/ProjectObjectCardEditModal.tsx`** — уже есть форма для карты объекта (~200 строк)
3. **`shared/components/projects/ProjectObjectCard.tsx`** — компонент отображения карты объекта
4. **`shared/stores/projectStore.ts`** — Zustand store для управления проектами

### Задачи
- Создать единый компонент `ProjectEditForm.tsx`, объединяющий:
  - Базовые поля (название, адрес, тип, площадь, стоимость, дата сдачи, сложность, статус, код, бригада)
  - Секцию карты объекта (из `ProjectObjectCardEditModal`)
- Использовать этот компонент в `page.tsx` вместо встроенной формы
- Удалить дублирующийся код из `page.tsx`

## План изменений

### 1. Создать: `shared/components/projects/ProjectEditForm.tsx`

**Содержимое:**
- Принимает props: `project: Project | null`, `editForm: Partial<Project>`, `setEditForm`, `onSave`, `brigades: Brigade[]`, `onClose`
- Секция 1: Базовые поля (из текущей формы в page.tsx)
- Секция 2: Карта объекта (перенести из ProjectObjectCardEditModal.tsx)
- Кнопки "Сохранить" и "Отмена"
- Использует UI-компоненты из `@/shared/components/ui/`

### 2. Создать: `shared/components/projects/ProjectEditForm.tsx` с подкомпонентами

**Поддержка двух режимов:**
- Режим "Базовые поля" (табы/аккордеон)
- Режим "Карта объекта" (табы/аккордеон)

### 3. Файл: `app/projects/page.tsx`

**Заменить:**
```tsx
import { Modal } from '@/shared/components/ui/Modal';
import { AddObjectForm } from '@/shared/components/dashboard/AddObjectForm';
// ... и встроенную форму редактирования
```

**На:**
```tsx
import { Modal } from '@/shared/components/ui/Modal';
import { AddObjectForm } from '@/shared/components/dashboard/AddObjectForm';
import { ProjectEditForm } from '@/shared/components/projects/ProjectEditForm';
```

**Изменения:**
- Удалить весь блок встроенной формы редактирования
- Заменить на: `<ProjectEditForm isOpen={showEditModal} onClose={...} editForm={editForm} setEditForm={setEditForm} onSave={handleSaveEdit} brigades={brigades} />`

### 4. (Опционально) Удалить `ProjectObjectCardEditModal.tsx`

Если он больше не используется в других местах — удалить как неиспользуемый.

## Итоговый список файлов

| Файл | Действие |
|------|----------|
| `shared/components/projects/ProjectEditForm.tsx` | **Создать** — единая форма редактирования |
| `app/projects/page.tsx` | Заменить импорт, удалить встроенную форму, использовать `ProjectEditForm` |
| `shared/components/projects/ProjectObjectCardEditModal.tsx` | Удалить (если не используется) |

## Верификация

1. Открыть страницу `/projects`
2. Кликнуть "Добавить объект" — форма создания должна работать как прежде
3. Кликнуть "Редактировать" на карточке проекта — должна открыться модалка с единой формой
4. Переключаться между секциями "Базовые" и "Карта объекта"
5. Заполнить поля и нажать "Сохранить" — данные должны обновиться в store
6. Нажать "Отмена" — модалка должна закрыться без сохранения
7. Проверить, что приложение собирается без ошибок (`npm run build`)
