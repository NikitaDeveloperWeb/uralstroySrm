# Backend Implementation Plan

## Текущее состояние
- **Next.js 16.2** (App Router, React 19)
- **Prisma 6.19** + **SQLite** (dev.db)
- **14 моделей** в schema.prisma
- **Mock-данные** в `shared/data/`
- **Нет API routes** - весь frontend на статических данных

- ✅ **Без auth** - открытый API на этапе разработки

### API Response Helpers (shared/lib/api-response.ts)
```typescript
import { NextResponse } from 'next/server';

export function successResponse(data: unknown, status = 200) {
  return NextResponse.json({ success: true, data }, { status });
}

export function errorResponse(message: string, status = 400, errors?: unknown) {
  return NextResponse.json(
    { success: false, error: message, ...(errors && { errors }) },
    { status }
  );
}
```

### Template для route.ts
```typescript
import { NextRequest, NextResponse } from 'next/server';
import { prisma } from '@/lib/prisma';
import { successResponse, errorResponse } from '@/shared/lib/api-response';
import { createProjectSchema, updateProjectSchema } from '@/shared/lib/validators';

export async function GET(request: NextRequest) {
  try {
    const { searchParams } = new URL(request.url);
    const status = searchParams.get('status');
    const brigadeId = searchParams.get('brigadeId');
    
    const where: any = {};
    if (status) where.status = status;
    if (brigadeId) where.brigadeId = Number(brigadeId);
    
    const projects = await prisma.project.findMany({
      where,
      include: {
        brigade: true,
        materials: true,
        completedWorks: true,
      },
      orderBy: { createdAt: 'desc' },
    });
    
    return successResponse(projects);
  } catch (error) {
    console.error('GET /api/projects error:', error);
    return errorResponse('Failed to fetch projects', 500);
  }
}

export async function POST(request: NextRequest) {
  try {
    const body = await request.json();
    const validated = createProjectSchema.parse(body);
    
    const project = await prisma.project.create({
      data: validated,
      include: {
        brigade: true,
        materials: true,
        completedWorks: true,
      },
    });
    
    return successResponse(project, 201);
  } catch (error) {
    if (error instanceof Error && 'issues' in error) {
      return errorResponse('Validation failed', 400, error);
    }
    console.error('POST /api/projects error:', error);
    return errorResponse('Failed to create project', 500);
  }
}
```

## Seed данных (prisma/seed.ts)
```typescript
import { PrismaClient } from '@prisma/client';
import { initialProjects } from '../shared/data/projects';
import { initialBrigades } from '../shared/data/brigades';
import { initialWarehouseItems } from '../shared/data/warehouse';

const prisma = new PrismaClient();

async function main() {
  console.log('Seed: Starting...');
  
  // Brigades
  for (const b of initialBrigades) {
    await prisma.brigade.upsert({
      where: { id: b.id },
      update: {},
      create: b,
    });
  }
  console.log(`Seed: Created ${initialBrigades.length} brigades`);
  
  // Projects
  for (const p of initialProjects) {
    await prisma.project.upsert({
      where: { id: p.id },
      update: {},
      create: p,
    });
  }
  console.log(`Seed: Created ${initialProjects.length} projects`);
  
  // Warehouse
  for (const w of initialWarehouseItems) {
    await prisma.warehouseItem.upsert({
      where: { id: w.id },
      update: {},
      create: w,
    });
  }
  console.log(`Seed: Created ${initialWarehouseItems.length} warehouse items`);
  
  // Notifications
  await prisma.notification.createMany({
    data: [
      { type: 'low-stock', message: 'Цемент М500 заканчивается', priority: 'medium', link: '/warehouse', date: new Date(), itemId: 2 },
      { type: 'out-of-stock', message: 'Арматура А500С отсутствует', priority: 'high', link: '/warehouse', date: new Date(), itemId: 4 },
      { type: 'low-stock', message: 'Профнастил С8 на исходе', priority: 'medium', link: '/warehouse', date: new Date(), itemId: 8 },
      { type: 'overdue', message: 'Проект "Баня на берегу" просрочен', priority: 'high', link: '/projects/7', date: new Date(), projectId: 7 },
    ],
    skipDuplicates: true,
  });
  console.log('Seed: Created notifications');
  
  console.log('Seed: Completed!');
}

main()
  .catch((e) => {
    console.error(e);
    process.exit(1);
  })
  .finally(async () => {
    await prisma.$disconnect();
  });
```

## Вёрификация
1. `npm install zod` - установить валидатор
2. `npx prisma generate` - сгенерировать клиент
3. `npx prisma db push` - создать таблицы
4. `npx prisma db seed` - заполнить данными
5. `npm run dev` - запустить сервер
6. Тесты API:
   ```bash
   curl http://localhost:3000/api/projects
   curl -X POST http://localhost:3000/api/projects \
     -H "Content-Type: application/json" \
     -d '{"name":"Тест","area":"50","address":"Тест","type":"дом","cost":500000,"deadline":"2027-01-01","complexity":"средний","code":"test001"}'
   curl http://localhost:3000/api/brigades
   curl http://localhost:3000/api/warehouse
   ```
7. Проверка валидации:
   ```bash
   curl -X POST http://localhost:3000/api/projects \
     -H "Content-Type: application/json" \
     -d '{"name":"","cost":-100}'  # должен вернуть 400
   ```
